# Crux Finance

## Overview

[cruxfinance.io](https://cruxfinance.io/) offers an all-in-one platform for portfolio management, analytics, and trading tools within the Ergo ecosystem.

Crux also maintains [ergo-address-labels](https://github.com/cruxfinance/ergo-address-labels), a public registry for protocol address metadata. The repository is designed so projects can submit labels for contract addresses or ErgoTrees through pull requests, and the data can be reused by wallets, explorers, and analytics tools.

## Recent updates

- `Jul 12`: the legacy `ergodex.io` domain moved to Crux Finance and now redirects to the [Crux beta](https://beta.cruxfinance.io/). Spectrum remains the separate DEX project documented on the [Spectrum page](spectrum.md).
- `Jan 7`: [USE analytics](https://cruxfinance.io/use-analytics) went live.
- `Dec 2025` to `Jan 2026`: Crux frontend work added trending, gainers and losers boxes, loading states, logo fixes, and USE analytics.
- `Jan 7` to `Jan 14`: Crux tracked `USE/USDT` liquidity on Binance Chain and followed the USE and DexyGold DefiLlama adapter work.
